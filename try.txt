Step 118
Two png figures (chimeras_annotation_fractions.png and fragments_annotation_fractions.png) show
the genomic origin of S-chimeras (fig 3c), and three folders in the base directory; one folder to
 the first chromosome chimeras, one folder to the second chromosome chimeras, and third folder to
 the between chromosomes chimeras. Each folder contains two png figures for each experiment, with
 and without annotations. The figures show the total number of chimeric fragments for each combination of genomic elements (Fig 3d).

Step 119
Figures at the base directory show the distribution of S-chimeras associated with the sRNAs_number highest sRNAs. For
each of the following: fragments, chimeras number, and RILseq reads two figures are generated; one to all S-chimeras,
the other to between-chromosomes chimeras (chimeras that RNA1 and RNA2 are mapped to different chromosomes) (figure 3e).
By using --RNAseq_counts option, another two figures will be generated, show the sRNAs distribution according to the
RNAseq results.

Step 120
An excel file at the base directory. The file contains the unifies results with a new column, called "# of libraries",
contains the number of replicates the chimera appears in. "U" represents that the chimera does not appear at any
replicate but appears in the unified results. The new excel contains rename columns and chromosome names.
